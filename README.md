This program was developed as a banking application that allows users to create and manage bank accounts. When accessing the application, users can choose to create a new account or view information for an existing account.

The application allows users to perform common banking transactions, including depositing funds, withdrawing funds, and transferring money between accounts. The system keeps track of account balances and updates the 
appropriate accounts whenever a transaction is completed.

The purpose of this program is to provide a simple and organized banking system while demonstrating fundamental programming concepts such as data management, user input, conditional logic, and transaction processing. 
The application provides users with an easy way to manage multiple accounts and perform basic financial operations.
